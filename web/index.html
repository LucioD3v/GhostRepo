Raise your dead JavaScript from the grave.

Paste a GitHub link to an abandoned web app. GhostRepo checks whether it can rise, rewrites legacy patterns with codemods that only touch what is provably safe, and runs the original and the resurrected app side by side.

  • JavaScript
  • HTML pages and their scripts
  • ES5 and jQuery-era web apps

JavaScript, not Java: they are different languages. Repositories in other languages are detected and you are told why before any work is done.

Public repositories only. Nothing is downloaded or run until you say so.

The ritual, in four phases

  1. 🔮

    Necromancy

    Reads the repository from GitHub and finds every JavaScript file worth reviving. Python, Java or PHP projects are told so here, before anything else happens.

  2. ✝️

    Exorcism

    Replaces innerHTML = 'plain text' with textContent. Dynamic HTML is flagged for a human, never rewritten blindly.

  3. ⚗️

    Transmutation

    Turns var into const or let, and == into === when both sides are known to have the same type.

  4. 👻

    Resurrection

    Shows every change next to the original, runs both versions, and gives you a patch and a ready-to-paste pull request.

What it can raise

✅ Rises today

  • JavaScript web apps: .js files and the HTML pages that load them
  • ES5 code, jQuery-era sites, old browser and Firefox OS apps
  • A whole repository, or just one folder of it

🪦 Stays buried, for now

  • Java, Python, PHP, C#, Ruby and other languages: detected and explained, not modified
  • Private repositories
  • Running the repository's own tests

The Zero Breaking Logic vow

Provably safe or untouched. A rewrite is applied only when the syntax proves the behavior stays the same.

Nothing hidden. Every skipped site is listed with its reason and line.

Measured, not guessed. Every number comes from the actual code before and after.

Everything runs in your browser; no code is sent to any server of ours. Public GitHub repositories only. GhostRepo does not run a repository's own tests, so review the diff before you merge anything.
